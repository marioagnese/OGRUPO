# oGrupo local assets

Drop your Gemini fire-pit image here in Codespaces, named exactly:

`firepit-hero.jpg`

Expected URL: `/assets/firepit-hero.jpg`

In Codespaces Explorer: open `public/assets`, then drag the JPG from your computer into the folder (or right-click the folder and select **Upload...**). The homepage will use the local image as soon as the file is present.

Optional **local development only** soundtrack: put a file you have permission to use at `public/assets/preview-music.mp4`. The local development toggle uses its audio; it is not required for the visual preview. Do not commit a third-party copyrighted recording to the public repository without authorization.

Run `npm install` and `npm run dev`; open the forwarded port 3000. Review changes on branch `dev` before merging into `main`.
